# ADR-0002: Game title — The Vesper Bell

- **Status:** Accepted
- **Date:** 2026-09-27
- **Decider:** Owner
- **Bead:** `mw-e39.2`

## Decision

The game is called **The Vesper Bell**. "Merlin's Wrath" remains only as the original codename. The GitHub
repository is renamed to `davetashner/thevesperbell`. The priory in the story is renamed from Bellhollow to
**Bellwater Priory** to avoid echoing an existing title ("Vesper the Hollow Bell").

## Context

"Merlin's Wrath" was a working title. Merlin is not in the story, and "wrath" promises grimdark revenge
where the game's turn is the opposite: the monster is a guardian and the solution is a lullaby rung on a
bell (story bible §1). The story bible shortlisted *Nightjar — The Labyrinth Beneath Briar Glen* (top pick)
and *The Vesper Bell* (runner-up).

## Consequences

- The Nightjar stays the name of the dreaming creature inside the game.
- Bibles, prompt preambles, the story page and `backlog.html` use "The Vesper Bell".
- Title key art and logo beads are unblocked; the title is typeset (style bible forbids text in images).
